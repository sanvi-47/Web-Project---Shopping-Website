🛒 Shopping Website
📌 Project Description

Developed a responsive e-commerce web application for browsing and purchasing electronic products. The application includes product listing, category filtering, search functionality, and a dynamic cart system using JavaScript.

🚀 Features
🛍️ Browse products across categories (Mobile, Laptop, Watches)
🔍 Real-time search functionality for filtering products
🧾 Add to cart and view selected items
🧮 Dynamic cart total calculation
❌ Clear cart functionality
💳 Checkout button (basic implementation)
📱 Responsive UI design for different screen sizes
📂 Organized modular JavaScript files for scalability
🧠 Functionality Highlights
Implemented category-based filtering using JavaScript functions
Used event-driven programming for user interactions
Managed cart data dynamically (likely using localStorage/session)
Designed dropdown navigation for better UX
Integrated multiple pages (Home + Cart)
